# 文件名优化工具

一个简单的在线工具，用于优化文件名并去除重复项。

## 功能特点

- 去除重复的文件名
- 优化不合法的文件名字符
- 处理超长文件名
- 优化中文标点符号
- 实时显示处理日志
- 详细的优化统计信息

## 使用方法

1. 访问 [工具页面](https://你的用户名.github.io/你的仓库名/)
2. 在左侧文本框中粘贴需要处理的文件名（每行一个）
3. 点击"一键优化"按钮
4. 在右侧文本框中查看优化后的结果
5. 使用"复制结果"按钮复制优化后的文件名
